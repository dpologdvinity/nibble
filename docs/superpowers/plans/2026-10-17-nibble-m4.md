# nibble M4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Q8_0/Q4_0 weights matching llama.cpp, a seeded sampler, and streaming multi-turn chat (`nibble chat`) on Qwen2.5-0.5B — spec milestone M4.

**Architecture:** Quantized matmul follows llama.cpp: activations are quantized to Q8_0 per row, then integer block dot products against Q4_0/Q8_0 weights (scalar reference only; SIMD is M6). A new `Sampler` turns logits into tokens. Chat formatting (ChatML) lives in the library behind `nibble::Chat`, which keeps the KV cache between turns and prefills only the new turn.

**Tech Stack:** unchanged (C++20, g++ 13, CMake, Catch2 v3.16.1, clang 18 for fuzz). `llama-quantize` (already built in `third_party/build/bin/`) makes the test models.

**Spec:** `docs/superpowers/specs/2026-10-17-nibble-design.md` (§5.1 quantized matmul, §3.5 chat templates, §9 M4). Ledger of deferred items: `docs/superpowers/plans/2026-10-17-nibble-m0-m3-ledger.md`.

## Decisions this plan makes (for review)

1. **Test models are made locally with `llama-quantize --pure`** from the F16 file, so every 2-D tensor is exactly Q8_0 or Q4_0. Official Hugging Face Q4_0 files mix in Q6_K/Q8_0 for some tensors and can't load until v1.1 (K-quants).
2. **Library sampling defaults match llama.cpp:** temperature 0.8, top-k 40, top-p 0.95, random seed unless one is given. `temperature = 0` means greedy.
3. **Chat keeps the KV cache between turns.** The scalar engine prefills at about 1–4 tok/s, so re-prefilling the whole history each turn is too slow. When the context fills, the chat ends with `ContextFull`; there is no sliding window (spec §2).
4. **Qwen's default system prompt** `You are Qwen, created by Alibaba Cloud. You are a helpful assistant.` is used when none is given (that is what Qwen2.5's own template does).
5. **`n_ctx` larger than the model's `context_length` is an error**, not a silent clamp.
6. **User text in chat is tokenized with `parse_special = false`**, so a user typing `<|im_end|>` cannot inject control tokens. Template markup uses `parse_special = true`.

## Global Constraints

- All M0–M3 Global Constraints still hold (C++20; `-Wall -Wextra -Wpedantic -Werror` under g++ 13 and clang 18; `nibble::Error` naming the offending value; untrusted GGUF; no allocation in `Transformer::forward` or backend ops; model code never dereferences activations; `models/` gitignored).
- **No allocation in the decode step either:** `Sampler::sample` and the quantized matmul use buffers sized up front (sampler at construction, Q8_0 activation scratch at `Backend::reserve`). Token-string handling may still allocate (ruling R3).
- Q8_0 activation quantization must match llama.cpp's `quantize_row_q8_0_ref` exactly: per 32-element block, `amax = max|x|`, `d = amax / 127`, `id = d ? 1/d : 0`, stored scale `fp32_to_fp16(d)`, `q[i] = roundf(x[i] * id)`.
- Q4_0 block (18 bytes): `uint16 d` (fp16), then 16 bytes; byte `j` holds element `j` in the low nibble and element `j + 16` in the high nibble; value = `((nibble) − 8) · d`. Q8_0 block (34 bytes): `uint16 d`, 32 × `int8`; value = `q · d`.
- Block dot (both types): integer sum `Σ qw·qa` over the block, then `sum += (float)isum * fp16_to_fp32(dw) * fp16_to_fp32(da)`; accumulate rows in float.
- E2E thresholds unchanged for every model: cosine ≥ 0.999; near-tie when golden or nibble top-2 gap < 1e-3.
- Conventional Commits, subjects ≤ 72 characters, no attribution trailers. Work on branch `feat/m4`. Do not push.

## Review Focus

1. **Activation rows whose 32-block is all zeros:** `d = 0` must give zero contributions, not NaN. Test: Task 2 `zero block quantizes to zero`.
2. **A chat turn that would overflow the context:** must stop with `ContextFull` before writing past the KV cache, including when the new turn's prompt alone doesn't fit. Test: Task 6 `turn longer than remaining context`.
3. **Cancel mid-turn, then send another turn:** the next turn must continue from a consistent state (the cancelled token was never forwarded). Test: Task 6 `cancel then continue`.
4. **`top_k` larger than the vocab, `top_p` of 0 or ≥ 1, negative temperature:** clamp or reject predictably. Tests: Task 4 `parameter edges`.
5. **Untrusted names in error messages:** keys, tensor names and token text quoted in `nibble::Error` messages must be escaped. Test: Task 5 `error messages escape control bytes`.

### Task 4: Sampler

**Files:** Create `src/sampler.h`, `src/sampler.cpp`. Test: `tests/test_sampler.cpp`.

**Interfaces:**
- Produces (namespace `nibble`):
  ```cpp
  struct SamplerParams { float temperature; int top_k; float top_p; uint64_t seed; };
  class Sampler {
   public:
    Sampler(const SamplerParams&, int64_t n_vocab);   // preallocates candidate buffers; validates params
    int32_t sample(std::span<const float> logits);    // no allocation
  };
  ```
- Algorithm, in order: if `temperature == 0` → argmax (lowest index on ties). Otherwise: (1) keep the `top_k` highest logits (`top_k <= 0` or `>= n_vocab` → keep all), ties broken by lower index; (2) softmax of `logit / temperature` over the kept set, in double, max-subtracted; (3) sort kept descending by probability and keep the smallest prefix whose cumulative probability ≥ `top_p` (always ≥ 1 token; `top_p >= 1` keeps all); (4) renormalize; (5) draw `u ∈ [0, 1)` from the RNG and pick the first token whose cumulative probability exceeds `u`.
- RNG: xoshiro256** seeded through splitmix64 from `seed`; `u = (next() >> 11) * 0x1p-53`. (Own RNG so results are identical across standard libraries.)
- Validation: `temperature < 0`, NaN temperature, `top_p` NaN or < 0 → `nibble::Error` naming the value.

- [ ] **Step 1: Failing tests.**
  - `temperature 0 is argmax`; `top_k 1 is argmax` for any temperature.
  - `same seed same sequence`: 1000 draws from logits `{0, 1, 2, 3}` with seed 42 are identical across two Samplers; seed 43 differs somewhere.
  - `distribution`: logits `{0, ln 2}`, temperature 1, 200 000 draws → frequency of token 1 within 0.667 ± 0.005.
  - `top_p` cut: probabilities `{0.6, 0.3, 0.1}` (as logits) with `top_p = 0.5` → always token 0; `top_p = 0.85` → never token 2.
  - `parameter edges`: `top_k = 10⁶` behaves as all; `top_p = 0` keeps exactly the top token; negative temperature throws with the value in the message.
  - `sample does not allocate`: covered by a global operator-new counter in the test (count unchanged across 1000 calls).
- [ ] **Step 2–4: Verify failure, implement, pass.**
- [ ] **Step 5: Commit** `feat(sampler): seeded top-k/top-p/temperature sampler`.

    float temperature = 0.8f; int top_k = 40; float top_p = 0.95f;

  - `escape_control` moves to `src/util/escape.h` (namespace `nibble`); every `nibble::Error` message that quotes a key, tensor name, string value, or token text from the file passes it through it. `cli/cmd_info.cpp` uses the same function.
